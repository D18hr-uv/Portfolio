# Portfolio — Dhruv Bhardwaj

My personal portfolio — a refined, motion-rich single-page site built with **Next.js**,
**Tailwind CSS** and **Framer Motion**.

🔗 **Live:** [dhruvbhardwaj.vercel.app](https://dhruvbhardwaj.vercel.app/)

## Highlights

- Animated loading counter and reveal
- Oversized kinetic typography with scroll-driven reveals
- Smooth inertial scrolling (Lenis) and parallax accents
- Custom cursor + magnetic buttons (fine-pointer only, reduced-motion aware)
- Sections: Hero · About · Experience · Stack · Projects, with a dedicated `/resume` page

## Tech

Next.js (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion (`motion`) · Lenis · react-icons

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
```

Build for production:

```bash
npm run build
npm start
```

## Deployment

Deployed on **Vercel** (Next.js preset). Pushing to `main` triggers a production deploy.
